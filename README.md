# Chiram Text Compare Tool

## 📋 Overview

Chiram Text Compare Tool is a premium enterprise-grade text comparison platform built with a dark/light theme, advanced word-level diff highlighting, and real-time statistics.

### ✨ Key Features

- **🌓 Dark/Light Theme** - Toggle between themes with automatic localStorage persistence
- **⚡ Advanced Diff Algorithm** - LCS-based (Longest Common Subsequence) word comparison
- **🎨 Color-Coded Highlighting**
  - 🟠 Orange: Unchanged words
  - 🟢 Green: Added words
  - 🔴 Red: Removed words (with strikethrough)
- **📊 Real-Time Statistics**
  - Character difference count
  - Word difference count
  - Similarity percentage
  - Match status indicator
- **📱 Fully Responsive Design** - Optimized for desktop, tablet, and mobile
- **⚙️ Performance Optimized** - Cache-busting loader, instant comparisons
- **♿ Accessible** - WCAG compliance, keyboard navigation support
